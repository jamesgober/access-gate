# access-gate v0.5.0

Released 2026-11-11.

### Changed

- `Schema::fingerprint` now also covers what each role grants (inheritance
  resolved) and the guest grants, and opens each section with a marker no
  name can imitate. Two schemas that differ only in a permission or
  attribute named like a section no longer share a fingerprint, and a role
  that loses a permission changes it.

### Migrating from 0.4

- A fingerprint stored under 0.4 no longer matches: permission sets stored
  with it are refused once (sessions end once with gatekeeper-io).
- From now on, editing a role's grants changes the fingerprint, so stored
  permission sets carrying the old grant are refused instead of kept.
